Features
Recommended setup: every feature ON except Disable All Tweaks (OFF). Tap Apply recommended, review, then Save Config & Reload at the bottom.
Adaptive Governor Recommended ON
Frame-aware CPU governor. During a confirmed game it reads live frame stats + CPU/GPU load and shifts each cluster's max frequency between Eco and Max.
ONCPU cap follows real frame pacing — smoother heavy games (CoD), at the cost of extra heat & battery.
OFFNo frame-aware response; only base GameTurbo/thermal tuning runs.
GameTurbo Recommended ON
In-game boost engine: pins game threads (uclamp 90/max), raises priority/affinity, maxes DDR & GPU hints on combat bursts, lifts FPS caps, tunes I/O. Thermally aware with an 8s post-throttle cooldown.
ONHigher, steadier FPS in games; warmer & more battery drain during sessions.
OFFGames run stock scheduling — cooler, but visible stutter/lag spikes in demanding titles.
Advanced Tuning Recommended ON
Deeper SoC tuning applied on policy transitions: WALT scheduler, LLC/bus latency, ADPF, ZRAM/F2FS, freq floors & uclamp. Every knob is capability-probed and idempotent — safe no-ops on unsupported kernels.
ONUnlocks extra low-level optimizations beyond the base tuner.
OFFOnly base tuning is applied; these deep knobs stay untouched.
ML Shadow Inference Recommended ON
Learned temperature forecaster in shadow mode. When confident, it blends its prediction into the forecast (±2°C max) so cooling starts earlier. Never overrides EmergencyCool/Powersave hard rules.
ONEarlier, smoother proactive cooling from the trained model.
OFFLinear forecast only — fully reactive, temps rise slightly more before cooling kicks in.
Network Diagnostics Recommended ON
Probes live network quality (RTT/jitter) and applies in-game Wi-Fi tweaks: low-latency mode, Wi-Fi power-save off, qdisc removal.
ONLower, stable ping & better hit registration in multiplayer games.
OFFStock Wi-Fi power-save stays on — occasional latency spikes; no probing overhead.
Disable All Tweaks Recommended OFF
Master kill-switch (same mode the daemon forces in Safe Mode). Blocks every kernel write — the daemon becomes telemetry-only.
ONNothing is written to the kernel. Use to isolate instability or run stock; logs & WebUI keep working.
OFFNormal operation — all tuning, thermals and gaming optimizations active.
